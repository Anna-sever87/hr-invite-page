# Приглашение на собеседование — мини-проект для ДЗ (VPS + Docker + Coolify)

Простая статическая HTML-страница-приглашение на собеседование, упакованная в Docker-контейнер на nginx.
Нужна только для проверки, что автодеплой через Coolify работает — сам контент не главное.

## Файлы
- `index.html` — страница
- `Dockerfile` — сборка образа с nginx

## Как собрать и проверить локально (по желанию)

```
docker build -t hr-mini-site .
docker run -d -p 8080:80 hr-mini-site
```

Открыть: http://localhost:8080

## Как задеплоить на сервер через Coolify

1. Создать приватный репозиторий на GitHub, запушить туда эти файлы.
2. В GitHub: Settings → Deploy keys → добавить публичный ключ из Coolify (с Allow write access).
3. В Coolify: Add Project → Private repository → указать ссылку на репозиторий, ветка `main`.
4. В настройках деплоя указать порт: внутри контейнера — 80, снаружи — например 8080.
5. Нажать Deploy, дождаться сборки.
6. Открыть в браузере: `http://IP_сервера:8080`.
7. Настроить вебхук (Coolify → Webhooks → скопировать URL → вставить в GitHub → Settings → Webhooks).
8. Проверить автодеплой: поменять любую цифру в `index.html`, закоммитить и запушить — через минуту страница на сервере должна обновиться сама.

## Что можно поменять для теста автодеплоя
Проще всего — поменять дату/время собеседования в `index.html` и подпись версии внизу страницы.
